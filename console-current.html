若浏览器没有转发粘贴，请将鼠标移到 noVNC 左边缘展开工具条，打开 Settings → Clipboard，在剪贴板面板中发送文本。
noVNC 仅监听本机且不再要求额外 VNC 密码。Insight 账号密码仅输入远程 Chrome；请勿粘贴到本工作台、Floatboat 或任何 API 表单。
2
提交链接，或搜索词 + 数量

剪辑完成后审核
